# The Ancient Artifact — 3D Asset Portfolio Piece

A standalone 3D modeling and animation showcase demonstrating a complete asset creation workflow in **Autodesk Maya**. This project focuses on hard-surface modeling principles, clean topology, and structural transformation.

## 📐 Project Overview
* **Software:** Autodesk Maya
* **Pipeline:** High-Poly to Low-Poly workflow
* **Asset Type:** Prop / Environment Artifact
